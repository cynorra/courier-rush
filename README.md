# Courier Rush (working title)

An original arcade delivery-racing game built on Kenney's **Starter Kit Racing** (MIT code, CC0 art).
All game code beyond the starter kit is written from scratch for this project.

Credits: Kenney (https://kenney.nl): Starter Kit Racing (MIT), 3D models, sprites and sounds (CC0).
Clean-room rule: no code or assets are taken from other published games.
